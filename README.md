# OrderMate

일본 중소 도매업체를 위한 FAX 주문 AI 자동 입력 툴의 해커톤 포트폴리오입니다.
해커톤 주제 「일본 기업의 AX(AI Transformation) 개선을 위한 솔루션 제안」에 맞춰 만들었습니다.

**페이지 보기:** https://dahye292.github.io/ordermate-portfolio/

## 담긴 내용

- 2025~2026년 일본 통계를 근거로 한 문제 정의
- 인터랙티브 데모: FAX 수신 → AI 추출 → 담당자 확인 → 거래처 사전 학습
- 합성 테스트 FAX 10장(45줄) 실측 결과: 정답 43/45, 사람 확인 없이 통과한 오답 0건
- 실제 도입 사례 기준 ROI 계산기와 손익분기, 기존 서비스 비교, 로드맵

`index.html` 파일 하나로 동작합니다. 테스트 FAX 이미지도 파일 안에 들어 있습니다.
